SubtitleDB integration examples

Runnable pages that talk to the live API at api.thesubtitledb.org. These are what the end-to-end tests drive.

Players

  • The smallest page that works - a video, three options, one call. This is the copy printed in the integration guide
  • ArtPlayer - eager resolve on load, lazy fetch on select
  • Plain video element - no player library, srt and ass converted to WebVTT in the browser
  • Every supported player - one attach call against a real build of Video.js, Shaka, Vidstack, Plyr, DPlayer, Clappr, xgplayer, MediaElement.js, OpenPlayerJS and Media Chrome

Before running

npm install
npm run build
npm run vendor
npm run serve

npm run vendor copies the built packages and the ArtPlayer bundle into examples/vendor, which is generated and not committed. Nothing here loads anyone else's code from a CDN.
